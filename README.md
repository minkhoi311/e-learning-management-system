# E-learning-management-system
Hệ thống quản lý khóa học trực tuyến xây dựng bằng Java MVC, Spring Security, Hibernate, Thymeleaf và ReactJS, hỗ trợ phân quyền người dùng và quản lý khóa học hiệu quả.

##  Công nghệ sử dụng (Tech Stack)

###  Backend
- Java (kiến trúc MVC)
- Spring Framework
- Spring Security (xác thực & phân quyền)
- Hibernate (ORM – ánh xạ đối tượng quan hệ)

###  Frontend
- ReactJS
- Thymeleaf (render phía server)

###  Cơ sở dữ liệu
- MySQL

### Testing
- Postman
